Oui, le pack est optimisé pour Helix Native version 3.10 et supérieur. Il fonctionne parfaitement sous Windows 10 (version 1903 et plus récente) et Windows 11. Assurez-vous que votre version de Helix Native est à jour pour une compatibilité maximale.

Non, l'installeur ne modifie pas vos configurations personnelles. Les nouveaux plugins et presets sont ajoutés à côté de vos fichiers actuels. Vous pouvez les désactiver ou les supprimer à tout moment via l'outil de gestion inclus.
